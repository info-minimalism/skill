# Removable-Burden Taxonomy

**Applies to:** Info-Minimalism Standard v1.0.0

Categories describe observable expression, not creator intent.

| Code | Category | Test |
|---|---|---|
| `R1` | Referent over-specification | Could a shorter reference identify the same entity unambiguously in the declared context? |
| `R2` | Same-function restatement | Does another span already perform the same semantic or rhetorical job? |
| `R3` | Unnecessary recap | Does the assumed encounter already provide the recapped information without a demonstrated reminder need? |
| `R4` | Preamble | Can the lead-in be removed or shortened without weakening orientation, tone, or social function? |
| `R5` | Delayed payload | Is a principal payload withheld behind material that performs no necessary setup? |
| `R6` | Decorative elaboration | Do examples, adjectives, metaphors, or scene-setting consume attention without a distinct preserved function? |
| `R7` | Meta-commentary | Does the expression talk about announcing, explaining, or sharing instead of doing it? |
| `R8` | Capture prompt | Does a hook, suspense device, engagement request, or continuation prompt add no payload or necessary navigation? |
| `R9` | Platform boilerplate | Does conventional platform text add no necessary meaning or action path? |
| `R10` | Artificial fragmentation | Does splitting create avoidable navigation, repeated orientation, or delayed access? |
| `R11` | Cross-item duplication | Does a later item repeat an unchanged proposition beyond what the encounter model requires? |
| `R12` | Redundant format or modality | Does another modality repeat the same material without accessibility, reinforcement, or choice value? |
| `RX` | Other demonstrated burden | Use only with a precise preservation argument. |

## Necessary-cost protections

Do not annotate material as removable merely because it is repeated or long. Plausibly necessary functions include:

- first-mention identity and disambiguation;
- standalone orientation on an algorithmic feed;
- qualifications, modality, uncertainty, or scope;
- accessibility and translation;
- safety-critical warnings or action boundaries;
- memory support, deliberate practice, or spaced repetition;
- progressive explanation for a novice audience;
- rhetorical rhythm, humor, empathy, ceremony, or emotional effect when those are part of the expression's function;
- platform-imposed limits and navigation;
- summaries that let consumers exit before a longer treatment;
- distinct reminders whose timing is itself useful.

When necessity is plausible but unresolved, lower confidence or mark the span `contested`. Do not include contested or low-confidence cost in CRAC.
